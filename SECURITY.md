# Security policy

Pickframe runs locally and never uploads photos. The only network access is
the optional, user-initiated download of the CLIP model from Hugging Face,
verified by SHA-256.

## Reporting a vulnerability

Please report security issues privately through GitHub's
[security advisory form](https://github.com/lobojoel2003/Pickframe/security/advisories/new)
rather than a public issue. You can expect an answer within a week.

## Supported versions

Security fixes are released for the latest minor version.
