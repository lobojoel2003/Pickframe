# Contributing to Pickframe

Thanks for helping! Bug reports, test photos descriptions, docs fixes and code
are all welcome.

## Development setup

```bash
git clone https://github.com/lobojoel2003/Pickframe.git
cd Pickframe
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -e ".[dev]"
```

Run the checks before opening a pull request:

```bash
pytest
ruff check src tests tools && ruff format --check src tests tools
mypy
```

GUI tests run headless with `QT_QPA_PLATFORM=offscreen` (set automatically by
the test suite). On Linux you may need `libegl1` and `libxkbcommon0`.

## Project layout

| Path | What it is |
| --- | --- |
| `src/pickframe/analysis/` | Sharpness, exposure, faces/eyes and embeddings |
| `src/pickframe/grouping.py`, `scoring.py` | Groups, scores, picks and ratings |
| `src/pickframe/xmp.py`, `writer.py` | XMP sidecars and embedded JPEG XMP |
| `src/pickframe/pipeline.py`, `cache.py` | Running an analysis, caching results |
| `src/pickframe/cli.py`, `gui/` | Command line and desktop app |
| `src/pickframe/models/` | Bundled ONNX models (see `NOTICE.md`) |
| `tools/` | Model conversion, icons, demo shoot, build stamping |
| `packaging/` | PyInstaller spec, installers, icons |

## Models

The bundled models are generated by `tools/build_models.py`, which downloads
the upstream files, checks their SHA-256 and converts the MediaPipe TFLite
models to ONNX (verified against the TFLite interpreter). If you change the
models, bump `ANALYSIS_VERSION` in `pipeline.py` so cached results are redone.
